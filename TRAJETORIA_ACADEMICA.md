# Trajetória Acadêmica

## Formação Técnica

Em 2023 concluí a formação em Instalação e Reparação de Redes de Computadores pelo SENAI CTTI-MG.

Durante essa formação participei de atividades práticas envolvendo:

- Infraestrutura de redes
- Cabeamento estruturado
- Administração de sistemas Windows Server
- Active Directory
- Servidores DHCP
- GPO
- VPN
- Backup corporativo
- Segurança da Informação
- Virtualização

O projeto final consistiu no desenvolvimento de uma proposta completa de infraestrutura de rede para um ambiente corporativo, incluindo planejamento, documentação e implantação da arquitetura de comunicação.
