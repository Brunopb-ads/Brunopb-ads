# 🔌 Projeto 1 - TCC de Cabeamento Estruturado

## 📋 Descrição

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) no SENAI Horto, com foco na criação de uma infraestrutura de rede para o galpão de Automóveis e Mecânica.

O projeto contemplou o planejamento e a implementação de uma solução de cabeamento estruturado capaz de atender às necessidades de comunicação, conectividade e expansão futura do ambiente. 【1-a6cb0a】

## 🎯 Objetivos

- Planejamento da infraestrutura de rede.
- Organização do cabeamento estruturado.
- Distribuição de pontos de rede.
- Aplicação de boas práticas de documentação.
- Preparação do ambiente para crescimento futuro.

## 🛠 Tecnologias e Conceitos

- Redes de Computadores
- Cabeamento Estruturado
- Topologia de Rede
- Documentação Técnica
- Normas de Infraestrutura de TI

# 🏆 Projeto 2 - Plataforma de Recrutamento de Atletas

## 📋 Descrição

Projeto desenvolvido durante o 1º período do curso de Ciência de Dados e Inteligência Artificial da PUC Minas.

O objetivo foi desenvolver uma plataforma web voltada para a localização, divulgação e recrutamento de atletas de diferentes modalidades esportivas. O sistema busca aproximar atletas, equipes e recrutadores por meio de um ambiente digital centralizado. 【1-a6cb0a】

## 🎯 Funcionalidades

- Cadastro de atletas.
- Cadastro de equipes.
- Busca por modalidade esportiva.
- Divulgação de perfis esportivos.
- Centralização das informações de recrutamento.
- Organização do processo de seleção esportiva.

## 🛠 Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub

2026
